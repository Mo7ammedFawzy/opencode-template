# opencode-template

A starter template for projects that use OpenCode.

This repository serves as a reusable foundation: copy it (or use it as a GitHub template) as the starting point for any new project, so you begin with the same base files and conventions instead of setting them up from scratch.

## Usage

Create a new project from this template, then replace or extend the contents as needed. The template is intentionally bare — it has no language-specific tooling, so it fits whatever stack your project uses.

## Install core skills

After creating your project, install the default OpenCode skills:

```
npx skills add https://github.com/vercel-labs/skills --skill find-skills;
```
